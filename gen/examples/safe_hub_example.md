# Safe Hub Examples

Contoh prompt untuk lokasi aman (village, tavern, blacksmith).

---

## 🏘️ Village - Peaceful Morning

```
pixel art, first person view, medieval village, peaceful atmosphere,
morning, bright sunlight, clear weather,
cobblestone path and thatched houses,
muted earth tones, wooden door visible, none,
dark fantasy RPG game background, 16-bit style,
seamless environment, detailed pixel art
```

**Variations:**

```
pixel art, first person view, medieval village, tense atmosphere,
```
