# Base Prompt Template

Copy prompt di bawah dan ganti placeholder sesuai kebutuhan.

---

## Universal Template

```
pixel art, first person view, [LOCATION_TYPE], [ATMOSPHERE] atmosphere,
[TIME_OF_DAY], [LIGHTING], [WEATHER], [DETAIL_ELEMENTS],
[COLOR_PALETTE], [FOCUS_OBJECT] in view, [ENEMY_HINT],
dark fantasy RPG game background, 16-bit style,
seamless environment, detailed pixel art, game asset,
740x340 resolution
```

---

## Short Version (untuk AI yang limit karakter)

```
pixel art, first person view, [LOCATION_TYPE], [ATMOSPHERE], [TIME_OF_DAY],
[LIGHTING], [WEATHER], dark fantasy RPG background, 16-bit style
```

## Detailed Version (untuk hasil maksimal)

```
pixel art style, first person perspective, [LOCATION_TYPE] environment,
[ATMOSPHERE] atmosphere, [TIME_OF_DAY] setting, [LIGHTING] illumination,
[WEATHER] conditions, [DETAIL_ELEMENTS] scattered throughout,
[COLOR_PALETTE] color scheme, [FOCUS_OBJECT] visible in foreground,
subtle [ENEMY_HINT] in background, dark fantasy medieval RPG game,
16-bit retro pixel art, seamless tileable background,
atmospheric lighting, detailed environment design,
game asset for 2D RPG, resolution 740x340 pixels
```

| Tipe | Deskripsi | Mood |
|------|-----------|------|
| `village` | Pedesaan, jalan setapak, rumah-rumah | Peaceful/Tense |

| `blacksmith` | Interior bengkel, api unggun, perkakas | Warm/Gritty |
