## Quick Combos

### Forest + Combat Ready
```
pixel art, first person view, dark forest, ominous atmosphere,
night, moonlight, foggy, twisted trees and dense fog,
weapons rack visible, bones scattered, shadow movement,
cold blues, dark fantasy RPG background, 16-bit style
```

### Tavern + Cozy
```
pixel art, first person view, tavern interior, warm atmosphere,
evening, candlelight, wooden beams and barrels,
lanterns hanging, warm firelight, inviting warmth,
warm oranges, dark fantasy RPG background, 16-bit style
```

### Ruins + Mystery
```
pixel art, first person view, ancient ruins, mysterious atmosphere,
dawn, dim light, misty, crumbling pillars and ancient carvings,
glowing runes, altar visible, mystical presence,
cold blues and muted grays, dark fantasy RPG background, 16-bit style
```

### Castle + Horror
```
pixel art, first person view, castle dungeon, dread atmosphere,
midnight, minimal torchlight, damp weather,
chains and iron bars, bones scattered, extreme shadows,
deep blacks and blood reds, dark fantasy RPG background, 16-bit style
```

## Usage Tips

1. **Jangan terlalu banyak elemen** — pilih 3-5 yang paling penting
2. **Konsisten dengan atmosphere** — elemen harus match mood
3. **Prioritas visual** — elemen yang paling keliatan dulu
4. **Test prompt** — coba generate dulu, tambah elemen jika kurang
5. **Negative prompt** — gunakan untuk hindari elemen yang nggak diinginkan
