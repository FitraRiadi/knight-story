# Time of Day Variants

Variasi waktu untuk setiap kondisi pencahayaan.

---

## 🌅 Dawn (Subuh)

**Karakteristik:**
- Langit mulai terang (biru muda, pink)
- Cahaya lembut, bayangan panjang
- Udara dingin, embun
- Suasana: Harapan baru, permulaan

**Lighting Keywords:**
```
dawn, early morning, first light, sunrise beginning,
dim blue-pink light, soft shadows, cool tones
```

**Color Palette:**
```
soft pinks, pale blues, light purples, muted oranges
```

**Prompt Template:**
```
pixel art, first person view, [LOCATION], [ATMOSPHERE],
dawn, first light breaking, soft blue-pink illumination,
cool morning air, long shadows, [DETAILS],
[COLOR_PALETTE], dark fantasy RPG background, 16-bit style
```

**Contoh:**
```
pixel art, first person view, forest, mysterious atmosphere,
dawn, first light breaking, soft blue-pink illumination,
cool morning air, long shadows, dew on leaves,
cold blues and soft pinks, dark fantasy RPG background, 16-bit style
```

## Quick Reference Table

| Waktu | Cahaya | Bayangan | Mood |
|-------|--------|----------|------|
| Dawn | Lembut, biru-pink | Panjang | Harapan |
| Morning | Terang, emas | Jelas | Produktif |
| Afternoon | Kuat, putih | Pendek | Aktif |
| Evening | Hangat, oranye | Panjang | Tenang |
| Night | Dingin, biru | Dalam | Misterius |
| Midnight | Minimal, gelap | Ekstrem | Horror |
