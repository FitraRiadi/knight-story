# Atmosphere Variants

Variasi suasana untuk setiap mood. Copy dan kombinasikan dengan location template.

---

## 🌿 Peaceful

```
peaceful, calm, serene, tranquil, idyllic, pastoral
```

**Visual Cues:**
- Warm lighting (sunrise, golden hour)
- Soft colors (pastels, warm tones)
- Nature elements (flowers, birds, gentle wind)
- No threats visible

**Color Palette:**
```
warm oranges, soft yellows, gentle greens, sky blues
```

**Prompt Addition:**
```
warm sunlight, gentle breeze, peaceful atmosphere,
flowers blooming, birds flying, safe haven feeling
```

---

## ⚠️ Ominous

```
ominous, threatening, foreboding, menacing, dark, sinister
```

**Visual Cues:**
- Dark shadows, low lighting
- Storm clouds, approaching darkness
- Distorted shapes, twisted forms
- Subtle threat hints

**Color Palette:**
```
dark grays, deep purples, blood reds, sickly greens
```

**Prompt Addition:**
```
dark clouds gathering, shadows deepening,
distant thunder, something watching, threat approaching
```

---

## ❓ Mysterious

```
mysterious, enigmatic, puzzling, unknown, secretive, arcane
```

**Visual Cues:**
- Fog, mist, obscured views
- Ancient symbols, runes
- Faint glow, magical particles
- Hidden paths, concealed doors

**Color Palette:**
```
cold blues, misty grays, faint purples, silver
```

**Prompt Addition:**
```
mysterious fog swirling, ancient symbols glowing,
hidden knowledge, arcane presence, secrets waiting
```

---

## 👻 Eerie

```
eerie, unsettling, creepy, haunting, strange, unnatural
```

**Visual Cues:**
- Unnatural lighting (green/blue hues)
- Distorted proportions
- Unexplained phenomena
- Isolation, emptiness

**Color Palette:**
```
sickly greens, pale blues, washed-out grays, ghostly whites
```

**Prompt Addition:**
```
unnatural silence, something feels wrong,
distorted shadows, eerie presence, unsettling atmosphere
```

---

## 🔥 Warm

```
warm, cozy, comfortable, inviting, safe, homey
```

**Visual Cues:**
- Firelight, candlelight
- Warm colors (oranges, yellows)
- Wooden textures, soft fabrics
- Signs of life (smoke, light)

**Color Palette:**
```
warm oranges, golden yellows, rich browns, amber
```

**Prompt Addition:**
```
warm firelight flickering, cozy atmosphere,
inviting warmth, safe haven, home feeling
```

---

## 🏜️ Desolate

```
desolate, barren, empty, lifeless, abandoned, forgotten
```

**Visual Cues:**
- Empty spaces, vast emptiness
- Ruins, decay, destruction
- No life, dead vegetation
- Harsh lighting (noon sun, cold moon)

**Color Palette:**
```
bleached whites, dusty browns, faded grays, rust
```

**Prompt Addition:**
```
abandoned wasteland, no signs of life,
empty silence, forgotten place, desolate atmosphere
```

---

## 😰 Tense

```
tense, anxious, suspenseful, on edge, alert, nervous
```

**Visual Cues:**
- Low lighting, deep shadows
- Restricted visibility
- Tight spaces, claustrophobic
- Movement in periphery

**Color Palette:**
```
dark grays, deep blacks, muted reds, cold blues
```

**Prompt Addition:**
```
tension building, something approaching,
hold your breath, ready for anything, suspenseful silence
```

---

## 😔 Melancholic

```
melancholic, sad, somber, mournful, sorrowful, bleak
```

**Visual Cues:**
- Overcast skies, rain
- Muted colors, low saturation
- Empty spaces, absence
- Signs of past life

**Color Palette:**
```
muted blues, washed-out grays, faded browns, pale greens
```

**Prompt Addition:**
```
somber atmosphere, rain falling softly,
memories of what was lost, melancholic feeling,
sad beauty, forgotten places
```

---

## 🌅 Hopeful

```
hopeful, optimistic, bright, promising, uplifting, new beginnings
```

**Visual Cues:**
- Bright lighting, sunrise
- Vibrant colors, clear skies
- Life, growth, renewal
- Open spaces, clear paths

**Color Palette:**
```
bright yellows, sky blues, fresh greens, warm oranges
```

**Prompt Addition:**
```
dawn breaking, new day beginning,
hope rising, light returning, promising atmosphere
```

---

## 😨 Dread

```
dread, terror, horror, fear, nightmare, nightmarish
```

**Visual Cues:**
- Extreme darkness, minimal light
- Horror elements (bones, blood, decay)
- Distorted shapes, unnatural forms
- Claustrophobic or vast emptiness

**Color Palette:**
```
deep blacks, blood reds, sickly greens, bone whites
```

**Prompt Addition:**
```
overwhelming dread, nightmare fuel,
terrifying presence, pure horror, fear incarnate
```

---

```
neutral, plain, ordinary, unremarkable, normal
```

- Standard colors

**Color Palette:**

**Prompt Addition:**

```
just another place, unremarkable, neutral mood
```

## 🎭 Atmospheric Combinations

### Peaceful + Mysterious
```
serene yet mysterious, calm with hidden secrets,
peaceful surface, mysterious undercurrent
```

### Ominous + Tense
```
threatening and tense, danger approaching,
foreboding atmosphere, ready to fight
```

### Warm + Melancholic
```
warm but sad, cozy yet mournful,
comfort tinged with loss, bittersweet warmth
```

### Eerie + Dread
```
unnatural horror, creeping dread,
eerie terror, nightmare fuel
```
