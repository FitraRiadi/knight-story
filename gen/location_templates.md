# Location Templates

Template spesifik per tipe lokasi. Copy dan ganti placeholder.

## 🏘️ Safe Hub (Village, Town, Camp)

### Template
```
pixel art, first person view, [LOCATION_NAME], [SAFE_ATMOSPHERE],
[TIME_OF_DAY], [SAFE_LIGHTING], [SAFE_WEATHER],
[SAFE_ELEMENTS], [SAFE_PALETTE],
[SAFE_FOCUS], none,
dark fantasy RPG game background, 16-bit style
```

### Variations

#### Peaceful Village
```

morning, sunlight, clear weather, cobblestone path and thatched houses,
muted earth tones, wooden door visible, none,
dark fantasy RPG game background, 16-bit style
```
